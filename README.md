### Работа с АПИ ЛЛМ  

Как агенты функционируют 
- Агент получает на вход запрос и может:

a) Обратиться к БД (RAG)   
b) Использовать тулы (внешние аппараты или другие сервисы, до 10 штук)  
с) Обращаться к памяти (уже пройденные вещи)

- На выходе какой-то результат 
- Данные проще использовать через pydantic в ООП

### Workflow

- Prompt chaining (несколько запросов подряд с ветвлением)
- Routing (Маршрутизация, выбор запроса по начальным условиям)
- Parallelizing (Выполняется набор действий одновременно и независимо друг от друга, хорошо для проверок условий и т.д.)
